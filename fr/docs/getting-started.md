# Premiers pas

Bienvenue dans Hear & Sing ! Ce guide vous accompagne lors de la configuration initiale afin que vous puissiez commencer à écouter immédiatement.

## Prérequis

- **iPhone ou iPad** avec iOS 18.0 ou version ultérieure
- Aucun compte ni connexion Internet requise après le téléchargement des fichiers

## Étape 1 — Installer l'application

Téléchargez Hear & Sing depuis l'App Store. Consultez le [guide d'installation](../installation/) pour plus de détails.

## Étape 2 — Importer votre premier fichier audio

Il existe trois façons d'ajouter de l'audio à votre bibliothèque :

### Option A — Feuille de partage (depuis Safari ou JW Library)

1. Dans Safari, accédez à une page de musique ou d'audio sur JW.org
2. L'onglet Naviguer de l'application affiche automatiquement une bannière **« Ajouter à l'app »**
3. Sélectionnez les pistes souhaitées, cochez éventuellement **Télécharger maintenant**, puis tapez **Ajouter**

### Option B — Sélecteur de fichiers (Files.app)

1. Ouvrez l'onglet **Bibliothèque**
2. Tapez le bouton **+** en haut à droite
3. Choisissez un fichier (MP3, M4A, AAC, OPUS ou FLAC) depuis Files.app
4. La piste apparaît immédiatement dans votre bibliothèque

### Option C — Extension de partage (depuis toute autre application)

1. Dans n'importe quelle application (ex. JW Library), tapez le bouton Partager sur un fichier audio
2. Choisissez **Hear & Sing** dans la feuille de partage
3. Le fichier est copié dans l'application en arrière-plan

## Étape 3 — Lire une piste

1. Ouvrez l'onglet **Bibliothèque**
2. Tapez n'importe quelle piste pour lancer la lecture
3. La **barre En lecture** apparaît au bas de chaque onglet
4. Tapez la barre pour ouvrir le lecteur plein écran avec curseur de défilement, contrôle de vitesse et file d'attente

## Étape 4 — Télécharger pour une utilisation hors ligne

Les pistes ajoutées depuis JW.org via l'onglet Naviguer peuvent ne pas encore être téléchargées. Une icône nuage indique qu'une piste n'est pas encore enregistrée localement.

- Tapez l'icône nuage sur une piste individuelle pour la télécharger
- Appuyez longuement sur une piste et choisissez **Télécharger** pour la mettre en file d'attente
- Dans l'onglet Bibliothèque, sélectionnez plusieurs pistes et tapez **Télécharger** pour un téléchargement groupé

## Étape 5 — Explorer l'audio biblique

1. Ouvrez l'onglet **Bibliothèque** et faites défiler jusqu'à la section **Bible**
2. Sélectionnez un livre dans la grille à 3 colonnes
3. Sélectionnez un chapitre dans la grille à 4 colonnes
4. Tapez un chapitre pour le lire, ou tapez **Tout télécharger** pour sauvegarder tous les chapitres d'un livre
